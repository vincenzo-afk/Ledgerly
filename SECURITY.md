# Security policy

## Supported version

Security fixes are considered for the current `main` branch.

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected vulnerability. Use GitHub's private vulnerability-reporting option from the repository **Security** tab when it is available. If private reporting is unavailable, contact the repository owner through the [GitHub profile](https://github.com/vincenzo-afk) and share only the minimum information needed to establish impact.

Include a clear description, affected files or behavior, reproduction steps, and any suggested mitigation. Do not include personal financial data, access tokens, or other secrets in a report.

## Scope

Ledgerly is a frontend-only project that stores expense records in the current browser. Security-relevant changes include client-side data exposure, unsafe export behavior, dependency vulnerabilities, and unintended transmission of local records.
